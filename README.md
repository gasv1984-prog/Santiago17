# Invitación — Cumpleaños de Santiago Andrés

Invitación web interactiva para el cumpleaños de Santiago Andrés Sánchez en Buggy Salento, el domingo 13 de septiembre de 2026.

## Ejecutar localmente

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Publicar en GitHub

1. Crea un repositorio vacío en GitHub.
2. Desde esta carpeta, ejecuta:

```bash
git init
git add .
git commit -m "Invitación de Santiago"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/TU-REPOSITORIO.git
git push -u origin main
```

Para publicar como sitio web, importa el repositorio en Cloudflare Pages, Vercel o Netlify y usa `npm run build` como comando de construcción.
